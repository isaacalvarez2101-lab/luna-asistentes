# Luna 🌙 — prototipo Android

Luna es un prototipo web instalable (PWA) para probar en Android.

## Funciones actuales
- Interfaz en español.
- Respuestas básicas de demostración.
- Lectura de respuestas mediante la voz del navegador.
- Reconocimiento de voz si el navegador lo admite.
- Lista de tareas guardada localmente en el dispositivo.
- Preparación para instalar como aplicación web.

## Publicar con GitHub Pages
1. En GitHub abre **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige la rama **main** y la carpeta **/(root)**; pulsa **Save**.
4. Espera a que GitHub Pages publique el sitio.
5. Abre la URL que GitHub indique en Chrome para Android.
6. En el menú de Chrome elige **Instalar aplicación** o **Añadir a pantalla de inicio**.

## Importante
Esta versión todavía **no está conectada a un modelo de IA**, no tiene backend ni sincronización en la nube, y no sustituye las alarmas/notificaciones del sistema. La voz depende de Chrome y de las voces instaladas. No añadas claves secretas ni contraseñas a este repositorio público.

La siguiente etapa es conectar un backend seguro con IA y después valorar una APK nativa si hace falta.
